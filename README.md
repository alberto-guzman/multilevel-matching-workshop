# Matching Methods for Multilevel Data in Education Research

Hands-on materials for the SREE 2026 workshop in Baltimore, Wednesday, September 23, 2026, taught by Jordan Rickles (UCLA) and Alberto Guzman-Alvarez (American Institutes for Research).

Everything is on the workshop site, including the setup instructions, the schedule, the slides, and the rendered code with its output.

- Site: https://alberto-guzman.github.io/multilevel-matching-workshop/
- Setup, do this before the workshop: https://alberto-guzman.github.io/multilevel-matching-workshop/before_you_come.html

## What is in the repository

| Path | Contents |
|---|---|
| `05_miad.qmd`, `06_cad.qmd`, `07_mcad.qmd` | The R code from Chapters 5, 6, and 7 of the handbook *Propensity Score Matching in Multilevel Educational Settings* (a draft), with the explanatory text removed. |
| `00_install_packages.R` | Installs the packages and checks the setup. Run once. |
| `data/` | The TIMSS 2015 dataset and its documentation. The treatment indicators were constructed from observed covariates and are not real interventions. |
| `checkpoints/` | Saved objects at the end of each Chapter 5 stage, for catching up if a chunk fails. |
| `slides/` | The lecture slides and the hands-on deck. |
| `tools/build_from_book.py` | Rebuilds the chapter files from the handbook source. |
