TipHow to use this document

Stage 1: Define estimand and understand data

Estimand for this example: the effect on the treated. We estimate the individual-average version first and the site-average version in Stage 5.

Stage 3: Implement matching method

Same call twice. One argument changes.

m_global <- matchit(
  formula  = ps_formula,
  data     = timss,
1  method   = "nearest",
2  distance = timss$pscore_fe,
  replace  = FALSE,
3  caliper  = 0.25,
  estimand = "ATT"
)

m_within <- matchit(
  formula  = ps_formula,
  data     = timss,
  method   = "nearest",
  distance = timss$pscore_fe,
4  exact    = ~school_id,
  replace  = FALSE,
  caliper  = 0.25,
  estimand = "ATT"
)
1
1:1 nearest-neighbor matching without replacement.
2
The Stage 2 score, passed as a vector.
3
Pairs can differ by at most 0.25 standard deviations of the score. Treated students with no comparison inside the caliper are dropped.
4
The within-site constraint: a treated student can only be paired with a comparison student in the same school. Partially-pooled matching changes this to exact = ~school_locale. Preferential within-site matching (same school first, another school as fallback) uses CMatching::MatchPW() and is on the Chapter 5 page.

A pooled SMD can hide imbalances that run in opposite directions in different schools. The multilevel-specific check is balance within each school.

1bal_within <- bal.tab(m_within, data = timss, cluster = "school_id",
                      binary = "std", abs = FALSE, un = FALSE)

covariate_labels <- var_labels[c("student_sex", "student_age", "student_math_conf",
                                 "student_like_math", "attend_preschool",
                                 "dad_edu", "mom_edu")]

matched_treated <- tibble(school_id = as.character(timss$school_id),
                          treated = timss$multisite_treatment,
                          w = m_within$weights) |>
  filter(treated == 1, w > 0) |>
  count(school_id, name = "n_treated_matched")

2within_smds <- bal_within$Cluster.Balance |>
  imap(\(tab, school_id) {
    tab$Balance |>
      rownames_to_column("covariate") |>
      dplyr::select(covariate, smd = Diff.Adj) |>
      filter(covariate %in% names(covariate_labels)) |>
      mutate(school_id = school_id)
  }) |>
  list_rbind() |>
  filter(is.finite(smd)) |>

A pooled SMD can hide imbalances that run in opposite directions in different schools. The multilevel-specific check is balance within each school.

```{r}
#| label: fig-within-school-balance
#| fig-cap: "Within-school standardized mean differences for the within-site matched sample. One point per school and covariate, sized by the school's matched treated count. The axis is truncated at 3."
#| fig-height: 4.5
#| fig-width: 7
#| code-line-numbers: true

bal_within <- bal.tab(m_within, data = timss, cluster = "school_id",   # <1>
                      binary = "std", abs = FALSE, un = FALSE)

covariate_labels <- var_labels[c("student_sex", "student_age", "student_math_conf",
                                 "student_like_math", "attend_preschool",

                          treated = timss$multisite_treatment,

  filter(treated == 1, w > 0) |>

within_smds <- bal_within$Cluster.Balance |>                          # <2>
  imap(\(tab, school_id) {
    tab$Balance |>
      rownames_to_column("covariate") |>

  filter(is.finite(smd)) |>
```

## Stage 5: Analyze outcomes

```{r}
#| code-line-numbers: true

outcome_formula <- math_score ~ multisite_treatment +
  student_sex + student_age + student_math_conf + student_like_math +
  attend_preschool + dad_edu + mom_edu                               # <1>

outcome_formula_within <- update(
  math_score ~ multisite_treatment *
    (student_sex + student_age + student_math_conf + student_like_math +
       attend_preschool + dad_edu + mom_edu),
  ~ . + factor(school_id)                                             # <2>
)

dat_within <- match.data(m_within)                                    # <3>

fit_within <- lm(outcome_formula_within, data = dat_within, weights = weights)

att_within <- avg_comparisons(
  fit_within, variables = "multisite_treatment",                      # <4>
  newdata = filter(dat_within, multisite_treatment == 1),
  wts     = "weights",                                                # <5>
  vcov    = ~subclass + school_id                                     # <6>
)
att_within |> dplyr::select(estimate, std.error, conf.low, conf.high)
```

1.  Student covariates only. The school fixed intercepts added next absorb the school covariates.
2.  Treatment-by-covariate interactions plus a fixed intercept per school, the outcome-model analogue of within-site matching.
3.  The matched rows with `weights` and a pair id (`subclass`).
4.  G-computation: set every treated student to treated and to comparison, take the difference in predictions, average over the treated students.
5.  The matching weights are 0/1 here. Under replacement, full, or ratio matching they are not, and dropping `wts` changes the estimand.
6.  Standard errors clustered on the matched pair and the school.

```{r}
#| code-line-numbers: true

fit_site <- lm(
  update(outcome_formula, ~ . + factor(school_id) +
           multisite_treatment:factor(school_id)),                   # <1>
  data = dat_within, weights = weights
)

cate_school <- avg_comparisons(
  fit_site, variables = "multisite_treatment",
  newdata = filter(dat_within, multisite_treatment == 1),
  wts = "weights",
  by = "school_id",                                                   # <2>
  vcov = ~subclass                                                    # <3>
)

att_site_avg <- hypotheses(cate_school, hypothesis = ~ I(mean(x)))    # <4>
att_site_avg |> dplyr::select(estimate, std.error, conf.low, conf.high)
```

1.  One treatment effect per school.
2.  One effect per school for that school's treated students.
3.  Pair-level clustering only: each school's effect is identified inside one school, so school-level clustering breaks down here.
4.  The site-average effect: the unweighted mean of the school effects, every school counting once. The FIRC model, the other route to a site-average effect, is on the Chapter 5 page.

## Stage 6: Sensitivity analysis

```{r}
#| code-line-numbers: true

fit_within_add <- lm(update(outcome_formula, ~ . + factor(school_id)),
                     data = dat_within, weights = weights)             # <1>

treatment_model_within <- lm(
  update(formula(fit_within_add), multisite_treatment ~ . - multisite_treatment),
  data = dat_within, weights = weights
)
r2dxj_x_within  <- partial_r2(treatment_model_within, covariates = "student_math_conf")
r2yxj_dx_within <- partial_r2(fit_within_add,          covariates = "student_math_conf")

att_add_within <- avg_comparisons(fit_within_add, variables = "multisite_treatment",
                                  vcov = ~school_id)
dof_within <- n_distinct(dat_within$school_id) - 1                     # <2>

sens_within <- sensemakr(
  estimate  = coef(fit_within_add)["multisite_treatment"],
  se        = att_add_within$std.error,
  dof       = dof_within,
  treatment = "multisite_treatment",
  r2dxj.x   = r2dxj_x_within,
  r2yxj.dx  = r2yxj_dx_within,
  benchmark_covariates = "student_math_conf",                          # <3>
  kd = 1:3, q = 1
)
sens_within$bounds$bound_label <- gsub("student_math_conf", "math confidence",
                                       sens_within$bounds$bound_label)
```

1.  An additive outcome model, so there is one treatment coefficient for the omitted-variable-bias framework.
2.  The school-clustered standard error and cluster-based degrees of freedom replace the model's own, which understate uncertainty under nesting.
3.  The observed covariate against which the robustness value is read.
